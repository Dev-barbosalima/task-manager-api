# 📌 Task Manager API

API REST para gerenciamento de tarefas desenvolvida com Java e Spring Boot.

---

## 🚀 Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

---

## 📂 Estrutura do projeto

- controller → endpoints da API
- service → lógica de negócio
- repository → acesso ao banco
- model → entidades

---

## 🔧 Funcionalidades

- Criar tarefa
- Listar tarefas
- Buscar por ID
- Atualizar tarefa
- Deletar tarefa
